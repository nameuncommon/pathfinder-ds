# Pathfinder DS v2 critique (2026-10-18)

The spec for the polish round. Two independent assessments (a design-director review of the rendered Storybook and /app/, and the impeccable detector) on main at c3c0208. Design context: `.impeccable.md`.

## Score and verdict
- Nielsen total 22/40 (acceptable). Weakest: flexibility and efficiency (1), then control, consistency, error prevention, recovery, help (2 each).
- Detector: 3 findings, all `overused-font` on Geist, owner-approved, false positive. No side-stripes, gradient text, card-grid or hero-metric patterns in code.
- Slop impression comes from layout and density: big-number tiles (Check "6 done yesterday", desktop "14", Introduction token counts), stacked identical cards, gold density, mono used for words ("due").

## What is working (keep)
1. Handwriting as content: read rows, the one-thing paper card, the correction sheet on paper.
2. Microcopy that cheers and never scolds.
3. Accessibility engineering: focus management, live regions, never colour alone, axe at error level in Chromium.

## Owner decisions (Jake, 2026-10-18)
- Scope: everything, including the gaps.
- Behaviour changes are built in code first; Figma screens follow; Jake reviews screenshots before anything merges.
- Order: start with the Storybook polish pass.

## Issues to fix
P1
1. Storybook defects: white second row in every docs do/don't table; TabBar "Librar / y" mid-word break; smudge tiles behind centred stories (pf-ambient on max-content boxes); Button States grid clipped; Dark/Light toggle on a dark-only system; docs title casing mixed.
2. Primary action out of thumb reach and no shutter: Snap's only visible button is Skip; Open's pinned slot is "Inbox · 3 to sort", which skips Snap and Check.
3. The pinned action slot changes meaning on every screen.
P2
4. Gold is not rare (Sort ~8 gold elements, desktop ~15; eight gold chips out-shout "Start Sunday plan").
5. No undo or acknowledgement for sort choices and fixes; "You can change it later" is unbacked.
6. Done ends on a flat receipt (browser bullets, 70% empty, "Start again").
Copy
7. "Your best Thursday this month" ranks (edges toward streaks); jargon "the read", "today's box", "spread" unexplained; "due" set in mono; Check rows have no fix affordance.
Storybook as portfolio
8. Introduction is text-only with stale copy ("four Foundations pages"); Color and Typography pages still v1 (blue ramp, light column, removed overdue chip; serif missing from the scale); Screens sits in the last sidebar slot.
Minor
9. Sticky action bar gradient stops at the column edge (hard vertical line over the glow); desktop "Moves Destination 2" gold text reads as a link; desktop day columns mostly empty.

## Gaps (in scope)
1. A reading state between snap and check, and low-confidence line flags on Check.
2. Sheet as a library component (the correction sheet's dialog shell).
3. A documented Screen action-bar pattern.
4. A Patterns section: action bar, undo toast, empty, offline, blurry, skipped, reading.
5. An Input error state.
6. A changelog and component status page.

## Out of scope
Light mode; new screens (week, inbox, library); replacing locked brand choices (navy, gold, cream, Cormorant Garamond, Geist, glass with fallback, the compass N/E/S/W mapping).
