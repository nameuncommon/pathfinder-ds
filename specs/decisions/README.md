# decisions

One file per decision that shapes `pathfinder-ds` (lightweight ADR). Naming: `NNN-short-slug.md`.

For the running one-line decision log (`what | why over the alternative`), see `decisions.md` at
the repo root - that file is the mandatory append-on-every-decision log; promote a decision here
only when it needs fuller context than one line.

Template:
```
# NNN - <decision title>
Date: <YYYY-MM-DD>  ·  Status: accepted | superseded by NNN

## Context
<what forced the decision>

## Decision
<what was chosen>

## Alternatives considered
<what was rejected and why>

## Consequences
<trade-offs accepted>
```
Delete this placeholder once real decisions land.
